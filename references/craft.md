# 通用制图功夫

与风格无关的部分：无论纸感、深色还是单色，这些都必须成立。

## 1. 先有重点，再有细节

- 一张图只允许 **一个** 主体（最重、最大、最深、或唯一带底色）。第二主体出现，重点消失。
- 主块的对比度/面积/位置至少有一项明显区别于其余；不要靠加粗所有文字来实现。
- 阅读顺序明确：从左到右、从上到下，或从中心向外；不要同时给两种顺序同等暗示。

## 2. 字体

- 字号层级用**比例**而不是感觉：标题 ≈ 正文 × 2.2–2.6，副标题 ≈ 正文 × 1.2。
- 一张图内的字号种类 ≤ 5（eyebrow / 标题 / 副标题 / 正文 / 元信息）。
- 正文下限：文档内嵌 12px、投屏 16px、导出大图 11px。低于此不要用缩小来塞字。
- 标签不超过 5 个词；一行不超过约 28 个汉字（或 56 个拉丁字符）。
- 全大写只用于 2–6 词的 eyebrow / 状态标记；中文不要用字间距模拟小字距。
- 不用斜体表达强调（中文斜体是伪斜体）；用字重、颜色、位置。

## 3. 颜色

- 颜色首先编码**语义**，其次才是好看。给每个颜色写一句「它代表什么」，写不出就别用。
- 同时用色相区分的类别 ≤ 5；再多就用位置、形状或标签。
- 文本对比度：正文 ≥ 4.5:1，大字（≥18px 粗体 / ≥24px）≥ 3:1。`lint_board.py` 会自动检查。
- 深色底上：正文用略带蓝/灰的浅色（如 `#A9BACD`），不要纯白满屏；强调色提亮一档。
- 中性灰至少保留两档：辅助信息与禁用/规划状态。
- 不要用红绿单独表达「好坏」——同时给形状或文字（可达性）。

## 4. 线与箭头

| 手法 | 含义 | 注意 |
| --- | --- | --- |
| 直线 | 对等连接、辐射、邻接 | 辐射图用它；层级图用它会让关系变模糊 |
| 正交折线 | 层级、归属、绕行 | 转折 ≤ 2 次；共线对齐 |
| 虚线 | 可选、异步、规划中、弱关系 | 一张图里只赋予它一种含义 |
| 粗细 | 主路径 2–3px，辅助 1–1.3px | 不要所有线同粗 |
| 箭头 | 方向性 | 双向才画双箭头；无方向的关联不要箭头 |

- 标签放在线的**中段侧边**，不要压线；水平线标签在线上方，垂直线标签在右侧。
- 尽量不交叉。交叉说明布局该换（换顺序、换方向、拆成两张）。
- 线不要穿过文字或卡片；绕行也要少。

## 5. 空间

- 间距成体系：4 / 8 / 12 / 16 / 24 / 40（同一张图只用其中 3–4 档）。
- 对齐优先于居中：左对齐的列比居中的卡片更容易扫读。
- 留白是强调手段：主体周围留更大空隙，比加框更有效。
- 画布比例服从介质：文档内嵌偏竖（4:5 ~ 1:1）、幻灯片 16:9、聊天预览偏方。
- 内嵌在文档里时，画布宽度 1400–1800 足够；文档中约按 420px 显示，缩得过小会糊。

## 6. 形状语义

- **框** = 一个有边界的单元（服务、模块、团队）。满屏都是框 = 没有边界信息。
- **嵌套** = 归属或包含；不要用嵌套表示「调用」。
- **重叠** = 共享边界或覆盖关系；需要图例解释。
- **圆/椭圆** = 参与者、数据、外部实体；**矩形** = 处理单元。不一致会让读者误读。
- 只用一种修饰：底色、描边、左侧色条，三者选一；叠加会发脏。

## 7. 密度

- 主块 ≤ 7（超出请拆图或分组）；层级 ≤ 3。
- 每个块 ≤ 4 行文字，每行一个动词短语。
- 图例 ≤ 5 项；能靠位置说明的不要进图例。
- 一张图回答一个问题。第二个问题另起一张。

## 8. 主题与令牌

`scripts/boardkit.py` 内置四套令牌，只提供颜色/圆角/线宽，不规定布局：

| 主题 | 地面 | 适合 | 特征 |
| --- | --- | --- | --- |
| `paper` | `#FAF8F3` | 文档插图、报告 | 暖白、发丝线、低圆角 |
| `slate` | `#FFFFFF` | 产品/白板、评审 | 白卡片、浅色描边、清爽 |
| `midnight` | `#0A0D12` | 工程深挖、投屏 | 近黑、细线、发光强调色 |
| `mono` | `#FFFFFF` | 极简、数据/归属图 | 纯黑白灰 + 一个信号色 |

新增主题只需给 `Theme(...)` 一组令牌（bg / ink / body / muted / line / surface / accents）。
主题不是风格：`paper` 既可以画条带，也可以画树或辐射。

## 9. 检查

画完先自问：

- [ ] 3 秒能说出主体与它连接的对象？
- [ ] 只有一个主体在争夺注意力？
- [ ] 每个颜色只有一种含义？
- [ ] 有没有任何文字 < 12px、或压线、或溢出框？
- [ ] 有没有交叉线可以靠换布局消除？
- [ ] 遮住文字后，几何结构仍然成立？

再跑一遍 `lint_board.py`，然后**看**导出的 PNG（不要只信代码）。
